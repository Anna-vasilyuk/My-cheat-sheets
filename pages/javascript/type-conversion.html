Перетворення типів даних

У JavaScript типи даних можна перетворювати двома способами: явно та неявно. У першому випадку програміст самостійно вказує, який тип потрібно отримати, а в другому — JavaScript виконує перетворення автоматично.

Явне перетворення

Явне перетворення типів даних (Explicit Type Conversion) відбувається тоді, коли програміст самостійно змінює тип значення за допомогою спеціальних функцій.

Найпоширеніші функції:

Number() Перетворює значення на число.
String() Перетворює значення на рядок.
Boolean() Перетворює значення на логічний тип.
Приклад коду
let numStr = "42";

let num = Number(numStr);

console.log(num); // 42
console.log(typeof num); // "number"

let boolStr = "true";

let bool = Boolean(boolStr);

console.log(bool); // true
console.log(typeof bool); // "boolean"
Що відбувається?

Number() перетворює рядок "42" на число 42. Boolean() перетворює непорожній рядок "true" на логічне значення true.

Неявне перетворення

Неявне перетворення типів даних (Implicit Type Conversion) відбувається автоматично, коли JavaScript самостійно змінює тип значення для виконання певної операції.

Приклад коду
let num = 42;

let str = "The answer is " + num;

console.log(str);
// "The answer is 42"

console.log(typeof str); // "string"
Що відбувається?

Коли число 42 додається до рядка, JavaScript автоматично перетворює число на рядок і об'єднує обидва значення.

У чому різниця?

Явне перетворення

Програміст сам вказує, який тип потрібно отримати.

Number("42") Перетворення виконується за командою.

Неявне перетворення

JavaScript самостійно перетворює тип даних.

"42" + 10 Перетворення відбувається автоматично.

Запам'ятай

Явне перетворення — програміст самостійно змінює тип даних.

Неявне перетворення — JavaScript автоматично змінює тип даних.

Number() — перетворення на число.

String() — перетворення на рядок.

Boolean() — перетворення на boolean.
