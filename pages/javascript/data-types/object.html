Що таке Object?

Об'єкт у JavaScript

Object (об'єкт) — це складний тип даних, який дозволяє зберігати декілька пов'язаних значень та функцій в одному місці.

Об'єкт можна порівняти зі звичайною чашкою. У неї є характеристики: колір, форма, матеріал та вага. А також дії, які з нею можна виконувати.

У JavaScript характеристики називаються властивостями (properties), а дії — методами (methods). 

const cup = {
    color: 'white',
    form: 'standard',
    material: 'porcelain',
    weight: 200
};

Властивості об'єкта (Properties)

Що таке властивості?

Властивості — це характеристики об'єкта, які описують його. Кожна властивість має назву та значення. 

const cup = {
    color: 'white',
    form: 'standard',
    material: 'porcelain',
    weight: 200
};

Щоб отримати значення властивості, можна звернутися до неї через крапку. 

console.log(cup.color);
// white

console.log(cup.weight);
// 200

Методи об'єкта (Methods)

Що таке методи?

Методи — це функції, які є властивостями об'єкта. Вони описують дії, які можна виконати за допомогою цього об'єкта. 

const cup = {
    drinkStart: function() {
        console.log('Drink start');
    },

    drinkEnd: function() {
        console.log('Drink end');
    }
};

Для виклику методу потрібно вказати назву об'єкта, крапку, назву методу та круглі дужки. 

cup.drinkStart();
// Drink start

cup.drinkEnd();
// Drink end

Повний приклад об'єкта

Об'єкт cup

Об'єднаємо властивості та методи в одному об'єкті.

const cup = {
    color: 'white',
    form: 'standard',
    material: 'porcelain',
    weight: 200,

    drinkStart: function() {
        console.log('Drink start');
    },

    drinkEnd: function() {
        console.log('Drink end');

};

Що потрібно запам'ятати?

  • Object — тип даних для зберігання пов'язаних даних.
  • Властивості (properties) описують характеристики об'єкта.
  • Методи (methods) описують дії об'єкта.
  • Для звернення до властивості використовують крапку.
  • Для виклику методу потрібні круглі дужки.
