Методи Math.floor(), Math.ceil(), Math.round() та Math.trunc()

Що таке округлення чисел?

У JavaScript для округлення чисел використовується вбудований об'єкт Math. Він містить спеціальні методи, які дозволяють округлювати числа різними способами.

Основні методи округлення: Math.floor(), Math.ceil(), Math.round() та Math.trunc(). Кожен із них працює за своїм правилом.

Math.floor() — округлення вниз

Метод Math.floor() округлює число вниз до найближчого цілого числа. Це означає, що він повертає найбільше ціле число, яке не перевищує початкове значення.

Приклад коду
let a = Math.floor(3.1);
let b = Math.floor(3.6);

console.log(a); // 3
console.log(b); // 3

console.log(Math.floor(-1.1)); // -2
Що відбувається?

Числа 3.1 та 3.6 округлюються до 3. Для від'ємного числа -1.1 результатом буде -2, оскільки округлення відбувається в напрямку мінус нескінченності.

Math.ceil() — округлення вгору

Метод Math.ceil() округлює число вгору до найближчого цілого числа. Він повертає найменше ціле число, яке не менше за початкове значення.

Приклад коду
let a = Math.ceil(3.1);
let b = Math.ceil(3.6);

console.log(a); // 4
console.log(b); // 4

console.log(Math.ceil(-1.1)); // -1
Що відбувається?

Числа 3.1 та 3.6 округлюються до 4. Число -1.1 округлюється до -1, оскільки округлення відбувається в напрямку плюс нескінченності.

Math.round() — округлення до найближчого цілого

Метод Math.round() округлює число до найближчого цілого. Якщо дробова частина менша за 0.5, число округлюється вниз, а якщо дорівнює або більша за 0.5 — вгору.

Приклад коду
let a = Math.round(3.1);
let b = Math.round(3.6);

console.log(a); // 3
console.log(b); // 4

console.log(Math.round(-1.1)); // -1
console.log(Math.round(-1.6)); // -2
Що відбувається?

Число 3.1 округлюється до 3, а 3.6 — до 4. Для від'ємних чисел також діє правило найближчого цілого, але при значеннях рівно посередині (наприклад, -1.5) Math.round() округлює в напрямку додатної нескінченності.

Math.trunc() — відкидання дробової частини

Метод Math.trunc() просто відкидає дробову частину числа, не округлюючи його. Він залишає лише цілу частину числа.

Приклад коду
let a = Math.trunc(3.1);
let b = Math.trunc(3.6);

console.log(a); // 3
console.log(b); // 3

console.log(Math.trunc(-1.1)); // -1
console.log(Math.trunc(-1.6)); // -1
Що відбувається?

У числах 3.1 та 3.6 дробова частина відкидається, тому результат дорівнює 3. Для від'ємних чисел -1.1 та -1.6 результат буде -1. Метод рухається в напрямку нуля.
