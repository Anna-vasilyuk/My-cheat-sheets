Що таке String?

Рядки (String)

String — це примітивний тип даних у JavaScript, який використовується для представлення текстової інформації. Рядок може містити літери, цифри, символи та пробіли. 

const greeting = "Hello!";
const name = "Anna";
const message = "Welcome to JavaScript!";

Як створювати рядки?

Три способи запису

У JavaScript рядки можна створювати за допомогою одинарних лапок (' '), подвійних лапок (" ") або зворотних лапок (` `). 

const first = 'Hello!';
const second = "Hello!";
const third = `Hello!`;

Усі три способи створюють значення типу String. Проте зворотні лапки мають додаткові можливості.

Незмінність рядків

Immutability

Після створення рядка не можна змінити окремий символ безпосередньо. Рядки в JavaScript є незмінними (immutable).

Метод replace() створює новий рядок із заміненим фрагментом, але початковий рядок залишається незмінним. 

let originalString = "Hello, world!";

let modifiedString = originalString.replace(
    "world",
    "JavaScript"
);

console.log(modifiedString);
console.log(originalString);

Шаблонні рядки

Template literals

Зворотні лапки (` `) дозволяють вставляти змінні безпосередньо в текст за допомогою конструкції ${}.

Також вони дозволяють створювати багаторядкові рядки без додаткових символів перенесення. 

const name = "Anna";
const age = 20;

const message = `Мене звати ${name}.
Мені ${age} років.`;

console.log(message);

Що потрібно запам'ятати?

  • String використовується для зберігання тексту.
  • Рядки можна створювати через одинарні та подвійні лапки.
  • Зворотні лапки дозволяють використовувати ${}.
  • Рядки є незмінними (immutable).
  • Метод replace() створює новий рядок.
  • Для перевірки типу можна використовувати typeof.
