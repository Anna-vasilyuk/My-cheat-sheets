Що таке BigInt?

Великі цілі числа

Тип BigInt дозволяє працювати з дуже великими цілими числами, які не можуть бути точно представлені типом Number.

Звичайний тип Number має обмеження: найбільше безпечне ціле число — 9007199254740991.

BigInt був доданий до JavaScript для роботи з цілими числами довільної довжини. Наприклад, він може бути корисним у криптографії та інших обчисленнях із великими числами. 

const bigNumber = 398479857587565565n;

console.log(bigNumber);

Особливості BigInt

BigInt і Number

Важливо пам'ятати, що не можна безпосередньо додавати значення типу BigInt і Number. Це призведе до помилки. 

const bigNumber = 398479857587565565n;
const baseNumber = 2;

console.log(bigNumber + baseNumber);

Як правильно додавати BigInt?

Щоб виконати додавання, обидва значення повинні мати тип BigInt. Для цього після цілого числа додається літера n. 

const bigNumber = 398479857587565565n;
const baseNumber = 2n;

console.log(bigNumber + baseNumber);

Що потрібно запам'ятати?

  • BigInt використовується для дуже великих цілих чисел.
  • Для створення BigInt використовують літеру n наприкінці числа.
  • BigInt і Number не можна безпосередньо додавати.
  • Для математичних операцій обидва значення повинні бути BigInt.
  • BigInt не підтримує дробові числа.
