Що таке Boolean?

Булевий тип даних

Boolean — це примітивний тип даних у JavaScript, який має лише два можливі значення: true (істина) та false (неправда).

Булеві значення використовуються для перевірки інформації та визначення того, чи є певна умова правильною або неправильною. 

const isLogged = true;
const hasPermission = false;

Перевірка типу даних

Оператор typeof

Для перевірки типу даних можна використовувати оператор typeof. Він повертає назву типу, до якого належить значення. 

const isLogged = true;

console.log(typeof isLogged);

// Результат: "boolean"

Що потрібно запам'ятати?

  • Boolean — примітивний тип даних.
  • Має лише два значення: true та false.
  • true означає істину.
  • false означає неправду.
  • Для перевірки типу використовується typeof.
