Оператор typeof

Як визначити тип даних у JavaScript

← Назад до типів даних

1. Що таке typeof?

typeof — це оператор JavaScript, який дозволяє визначити тип даних змінної або виразу.

Він повертає назву типу у вигляді рядка. Це корисно для перевірки даних та керування логікою програми. 

let age = 25;

console.log(typeof age); // "object"

2. Визначення різних типів даних

Оператор typeof можна використовувати для перевірки змінних із різними типами даних. 

let age = 25;
console.log(typeof age); // "object"

let name = "John";
console.log(typeof name); // "string"

let isStudent = true;
console.log(typeof isStudent); // "boolean"

3. typeof з дужками та без них

Оператор typeof можна використовувати як із дужками, так і без них. 

let age = 25;

console.log(typeof age);   // "object"
console.log(typeof (age)); // "object"

Якщо всередині дужок записати вираз, JavaScript спочатку обчислить його, а потім визначить тип результату. 

console.log(typeof (10 + 5)); // "object"
console.log(typeof ("Hello" + " world")); // "string"
