Що таке Array?

Масиви в JavaScript

Array (масив) — це впорядкована колекція значень. Значення всередині масиву називаються елементами.

Кожен елемент має свою числову позицію, яка називається індексом. 

const cups = [
    'cup0',
    'cup1',
    'cup2',
    'cup3',
    'cup4',
    'cup5'
];

Індекси масиву

З чого починається індексація?

Важливо пам'ятати, що індексація масиву починається з нуля, а не з одиниці. 

const cups = [
    'cup0',
    'cup1',
    'cup2'
];

console.log(cups[0]); // cup0
console.log(cups[1]); // cup1
console.log(cups[2]); // cup2

Різні типи даних в одному масиві

Масиви не типізовані

У JavaScript масив може містити значення різних типів даних одночасно: рядки, числа, булеві значення, об'єкти та навіть інші масиви.

Array — це об'єктний тип даних

Перевірка типу масиву

Масиви належать до об'єктного типу даних. Тому оператор typeof повертає object. 

const cups = ['cup0', 'cup1', 'cup2'];

console.log(typeof cups);
// object

console.log(Array.isArray(cups));
// true

Щоб точно перевірити, чи є значення масивом, використовують метод Array.isArray().

Що потрібно запам'ятати?

  • Array — об'єктний тип даних.
  • Масив зберігає впорядковану колекцію значень.
  • Елементи масиву мають індекси.
  • Індексація починається з 0.
  • В одному масиві можуть бути різні типи даних.
  • Для перевірки масиву використовують Array.isArray().
