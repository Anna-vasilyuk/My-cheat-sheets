Null та Undefined

У чому різниця?

Null та Undefined використовуються тоді, коли значення відсутнє. Але між ними є різниця. Щоб її зрозуміти, уявімо тримач для туалетного паперу.

0 — втулка є, паперу немає

Це нуль. Значення існує, і воно дорівнює 0. Нуль — це не відсутність значення. 

const number = 0;

console.log(number); // 0

null — є тримач, але він порожній

Ми свідомо залишили тримач порожнім. У JavaScript це означає, що значення навмисно відсутнє. 

const emptyValue = null;

console.log(emptyValue); // null

undefined — немає навіть тримача

Значення ще не було задане. Змінна оголошена, але їй нічого не присвоїли. 

let variable;

console.log(variable); // undefined

Перевірка типів

console.log(typeof 0);         // "number"
console.log(typeof null);      // "object"
console.log(typeof undefined); // "undefined"
