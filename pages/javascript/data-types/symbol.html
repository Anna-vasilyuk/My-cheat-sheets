Symbol

Що таке Symbol?

Symbol — це примітивний тип даних, який використовується для створення унікальних ідентифікаторів.

Навіть якщо створити два символи з однаковим описом, вони все одно будуть різними. 

const symbol1 = Symbol('id');
const symbol2 = Symbol('id');

console.log(symbol1 === symbol2);
// false

Порівняємо зі звичайними числами

const number1 = 1;
const number2 = 1;

console.log(number1 === number2);
// true

Коли використовується Symbol?

  • Для створення унікальних ідентифікаторів.
  • Для створення спеціальних властивостей об'єктів.
  • Щоб уникати випадкового збігу ключів в об'єктах.

Поки що достатньо запам'ятати, що кожен Symbol є унікальним. Детальніше ми розглянемо його в окремій темі.
