Що таке арифметичні оператори?

Арифметичні оператори використовуються для виконання математичних обчислень із числами. За їх допомогою можна додавати, віднімати, множити, ділити числа та знаходити залишок від ділення.

Основні арифметичні оператори

JavaScript підтримує п'ять основних арифметичних операторів:

+

Додавання двох чисел.

-

Віднімання одного числа від іншого.

*

Множення чисел.

/

Ділення одного числа на інше.

%

Знаходження залишку від ділення.

Оператор додавання (+)

Оператор + додає два числа та повертає їхню суму.

Приклад коду
let a = 10;
let b = 5;

let sum = a + b;

console.log(sum); // 15
Що відбувається?

Створюються дві змінні a і b зі значеннями 10 та 5. За допомогою оператора + їхні значення додаються. Результат 15 записується у змінну sum.

Оператор віднімання (-)

Оператор - віднімає одне число від іншого.

Приклад коду
let a = 10;
let b = 5;

let difference = a - b;

console.log(difference); // 5
Що відбувається?

Від числа 10 віднімається число 5. Отриманий результат 5 записується у змінну difference.

Оператор множення (*)

Оператор * використовується для множення двох чисел.

Приклад коду
let a = 10;
let b = 5;

let product = a * b;

console.log(product); // 50
Що відбувається?

Число 10 множиться на 5. Результат множення дорівнює 50 та записується у змінну product.

Оператор ділення (/)

Оператор / ділить одне число на інше.

Приклад коду
let a = 10;
let b = 5;

let quotient = a / b;

console.log(quotient); // 2
Що відбувається?

Число 10 ділиться на 5. Результат ділення дорівнює 2 та записується у змінну quotient.

Оператор залишку від ділення (%)

Оператор % повертає залишок, який залишається після ділення одного числа на інше.

Приклад коду
let dividend = 10;
let divisor = 3;

let remainder = dividend % divisor;

console.log(remainder); // 1
Що відбувається?

Число 10 ділиться на 3. Число 3 поміщається у 10 три рази, а залишок дорівнює 1. Саме це значення записується у змінну remainder.

Запам'ятай

+ — додає числа.

- — віднімає числа.

* — множить числа.

/ — ділить числа.

% — повертає залишок від ділення.
