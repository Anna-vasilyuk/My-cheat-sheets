Що таке оператори присвоювання?

Оператори присвоювання використовуються для присвоєння значення змінній. Найпоширенішим оператором присвоювання є знак =.

Оператор присвоювання (=)

Оператор = присвоює змінній значення, яке знаходиться праворуч від нього.

Приклад коду
let x = 10;

console.log(x); // 10
Що відбувається?

Змінній x присвоюється значення 10. Тепер під час звернення до x ми отримаємо 10.

Скорочені оператори присвоювання

У JavaScript існують скорочені форми присвоювання. Вони дозволяють виконувати математичну операцію та одночасно присвоювати змінній нове значення.

+=

Додає значення до змінної.

-=

Віднімає значення від змінної.

*=

Множить значення змінної.

/=

Ділить значення змінної.

Оператор +=

Оператор += додає вказане значення до поточного значення змінної та присвоює результат цій самій змінній.

Приклад коду
let y = 5;

y += 3;

console.log(y); // 8
Що відбувається?

Запис y += 3 означає те саме, що y = y + 3. До початкового значення 5 додається 3, тому нове значення y дорівнює 8.

Інші скорочені оператори

Приклади коду
let a = 10;
a -= 3;

console.log(a); // 7


let b = 5;
b *= 2;

console.log(b); // 10


let c = 20;
c /= 4;

console.log(c); // 5
Пояснення:

-= віднімає число від змінної. *= множить значення змінної. /= ділить значення змінної.

Запам'ятай

= — присвоює значення змінній.

+= — додає та присвоює.

-= — віднімає та присвоює.

*= — множить та присвоює.

/= — ділить та присвоює.
