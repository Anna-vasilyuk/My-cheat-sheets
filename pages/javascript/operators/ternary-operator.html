Що таке тернарний оператор?

Тернарний оператор (також відомий як умовний оператор) — це компактна заміна великої інструкції if / else. Він єдиний у JavaScript приймає одразу три операнди (три елементи для дії), через що й отримав свою назву.

Синтаксис виглядає наступним чином:

умова ? вираз1 : вираз2

Двигун JavaScript спочатку обчислює умову ліворуч. Якщо вона істинна (true), то виконується і повертається вираз1, інакше — виконується вираз2.

Визначення змінних залежно від умови

Найчастіше тернарний оператор використовується тоді, коли потрібно чітко визначити та записати значення у змінну на основі певної умови. Цей оператор «запитання» дозволяє зробити код значно коротшим і простішим для читання.

Приклад коду
let age = 25;
let message = age >= 18 ? 'Доросла людина' : 'Неповнолітній';

console.log(message); // "Доросла людина"
