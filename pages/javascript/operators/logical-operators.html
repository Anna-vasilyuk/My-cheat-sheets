Що таке логічні оператори?

Логічні висловлювання можуть набувати одного з двох значень: true (істинно) або false (хибно).

У JavaScript логічні оператори використовуються для роботи з логічними значеннями. Вони дозволяють об'єднувати умови, перевіряти їх та створювати складні логічні вирази.

Основні логічні оператори

&&

Логічне І (AND).

||

Логічне АБО (OR).

!

Логічне заперечення (NOT).

??

Нульове злиття (Nullish).

Логічне І (&&)

Оператор && повертає true лише тоді, коли обидві умови є істинними. Якщо хоча б одна умова хибна, результатом буде false.

Таблиця істинності
true  && true  // true
true  && false // false
false && true  // false
false && false // false
Як це працює?

Щоб результат був true, обидва значення повинні бути true. Наприклад, якщо потрібно перевірити, чи користувач повнолітній і чи має він документ, обидві умови мають виконуватися.

Приклад коду
let age = 20;
let hasDocument = true;

let result = age >= 18 && hasDocument;

console.log(result); // true

Логічне АБО (||)

Оператор || повертає true, якщо хоча б одна з умов є істинною. false повертається лише тоді, коли обидві умови хибні.

Таблиця істинності
true  || true  // true
true  || false // true
false || true  // true
false || false // false
Як це працює?

Для отримання результату true достатньо, щоб хоча б одна умова була істинною.

Приклад коду
let hasTicket = false;
let hasInvitation = true;

let result = hasTicket || hasInvitation;

console.log(result); // true

Логічне заперечення (!)

Оператор ! змінює логічне значення на протилежне: true перетворюється на false, а false — на true.

Таблиця істинності
!true  // false
!false // true
Як це працює?

Оператор ! заперечує значення, яке стоїть після нього. Якщо умова була істинною, результат стане хибним, і навпаки.

Приклад коду
let isOnline = true;

let result = !isOnline;

console.log(result); // false

Оператор нульового злиття (??)

Оператор ?? використовується для визначення значення за замовчуванням (fallback) для змінної. Він повертає праве значення тільки тоді, коли ліве значення є null або undefined.

Головна перевага над || (АБО)

На відміну від оператора ||, який замінює на дефолт будь-які "хибні" значення (як-от число 0 або порожній рядок ""), оператор ?? вважає нуль та порожній рядок правильними даними. Він спрацьовує виключно на порожнечу (null/undefined).

Приклад коду
let user = null;
let defaultUser = { name: 'Гість' };

let currentUser = user ?? defaultUser;

console.log(currentUser); // { name: 'Гість' }

Загальна таблиця істинності

У таблицях нижче можна побачити, як змінюється результат залежно від значень логічних висловлювань.

Оператори && та ||
 A      B      A && B     A || B

true   true     true       true
true   false    false      true
false  true     false      true
false  false    false      false
Оператор !
A       !A

true    false
false   true

Запам'ятай

&& — логічне І. Повертає true, якщо обидві умови істинні.

|| — логічне АБО. Повертає true, якщо хоча б одна умова істинна.

! — логічне заперечення. Змінює логічне значення на протилежне.

?? — нульове злиття. Забезпечує підстраховку лише для значень null та undefined.

true — істина.

false — хиба.
