Що таке оператори порівняння?

Оператори порівняння дозволяють визначати відношення між значеннями та відповідати на питання, чи є одне значення більшим, меншим або рівним іншому.

Результатом порівняння завжди є логічне значення: true або false.

Оператори менше та більше

< Менше

> Більше

Оператор < перевіряє, чи є ліве значення меншим за праве. Оператор > перевіряє, чи є ліве значення більшим за праве.

Приклад коду
let x = 5;
let y = 10;

let isLess = x < y;

console.log(isLess); // true
Що відбувається?

Число 5 менше за 10, тому результат порівняння — true.

Оператори менше або дорівнює та більше або дорівнює

<= Менше або дорівнює

>= Більше або дорівнює

Ці оператори перевіряють не тільки те, чи одне значення більше або менше за інше, а й чи дорівнюють вони одне одному.

Приклад коду
let x = 10;
let y = 10;

let isLessOrEqual = x <= y;

console.log(isLessOrEqual); // true
Що відбувається?

Значення x та y однакові — 10. Оператор <= враховує рівність, тому результат — true.

Оператор строгої рівності

=== Строго дорівнює

Цей оператор перевіряє, чи є два значення абсолютно однаковими. На відміну від звичайного порівняння (==), він порівнює не тільки самі значення, а й їхні типи даних [INDEX].

Приклад коду
let x = 5;
let y = "5";

let isStrictlyEqual = x === y;

console.log(isStrictlyEqual); // false
Що відбувається?

Значення x — це чисте число 5, а y — це текстовий рядок "5". Оскільки типи даних різні, оператор === повертає false [INDEX]. Якщо порівняти два однакових числа (5 === 5), результат буде true.

Оператор "in"

Оператор in використовується для перевірки, чи існує в об'єкті певна властивість [INDEX]. Він повертає true, якщо властивість існує, і false, якщо її немає.

Приклад коду
let person = {
    name: "John",
    age: 30
};

let hasName = "name" in person;
let hasAddress = "address" in person;

console.log(hasName); // true
console.log(hasAddress); // false
Що відбувається?

В об'єкті person є властивість name, тому результат true [INDEX]. Властивості address немає, тому результат false.

Запам'ятай

  • < — менше.
  • > — більше.
  • <= — менше або дорівнює.
  • >= — більше або дорівнює.
  • === — строго дорівнює (перевіряє значення і тип даних) [INDEX].
  • in — перевіряє наявність властивості в об'єкті [INDEX].
