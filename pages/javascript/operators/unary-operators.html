Що таке унарні оператори?

Це оператори, які працюють з одним операндом, тобто змінною або значенням.

Унарний плюс

Унарний плюс перетворює операнд на число, якщо це можливо.

Приклад коду
let num = "42";

let convertedNum = +num;

console.log(convertedNum); // 42
console.log(typeof convertedNum); // "number"
Що відбувається?

Змінна num містить рядок "42". За допомогою унарного плюса значення перетворюється на число 42.

02 / UNARY OPERATOR

Унарний мінус

Унарний мінус перетворює операнд на число та змінює його знак на протилежний.

Приклад коду
let x = 10;

let y = -x;

console.log(x); // 10
console.log(y); // -10
Що відбувається?

Значення змінної x залишається 10, а у змінній y записується число -10.

03 / UNARY OPERATOR

Логічне заперечення

Логічне заперечення (!) інвертує логічне значення операнда: true перетворює на false, а false — на true.

Приклад коду
let isTrue = true;

let isFalse = !isTrue;

console.log(isFalse); // false
Що відбувається?

Змінна isTrue містить true. Оператор ! змінює це значення на протилежне, тому isFalse отримує false.

Ще декілька прикладів
console.log(!0);       // true
console.log(!"Hello"); // false
console.log(!null);    // true
Зверни увагу!

Оператор ! спочатку перетворює значення на boolean, а потім інвертує його.

Інкремент та декремент

Інкремент ++

Збільшує значення змінної на одиницю.

Декремент --

Зменшує значення змінної на одиницю.

Інкремент та декремент мають дві форми використання: префіксну та постфіксну.

Дві форми використання

Розташування оператора впливає на те, яке значення буде використане у виразі.

Префіксна форма

Оператор розташований перед змінною. Спочатку змінюється значення, а потім використовується результат. 

let x = 10;

let y = --x;

console.log(x); // 9
console.log(y); // 9

Постфіксна форма

Оператор розташований після змінної. Спочатку використовується поточне значення, а потім змінна змінюється. 

let x = 10;

let y = x--;

console.log(x); // 9
console.log(y); // 10

Запам'ятай

+ — перетворює значення на число.

- — змінює знак числа.

++ — збільшує значення на 1.

-- — зменшує значення на 1.

Префікс — спочатку зміна, потім використання.

Постфікс — спочатку використання, потім зміна.
