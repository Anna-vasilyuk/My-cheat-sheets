Що таке пріоритет операторів?

У JavaScript різні оператори мають різний пріоритет. Це означає, що деякі операції виконуються раніше за інші, навіть якщо вони записані пізніше у виразі.

Якщо оператори мають однаковий пріоритет, порядок їх виконання визначається асоціативністю.

Пріоритет операторів

Оператори з більшим пріоритетом виконуються першими. Наприклад, множення має вищий пріоритет, ніж додавання.

Приклад коду
let a = 10;
let b = 2;
let c = 3;

let result = a + b * c;

console.log(result); // 16
Що відбувається?

Спочатку виконується множення 2 * 3 = 6, оскільки множення має вищий пріоритет. Потім виконується додавання 10 + 6 = 16.

Порядок виконання операцій у дужках

Вирази, які знаходяться у круглих дужках (), виконуються першими. Дужки дозволяють змінити стандартний порядок виконання операцій.

Приклад коду
let result = (10 + 2) * 3;

console.log(result); // 36
Що відбувається?

Спочатку виконується дія у дужках: 10 + 2 = 12. Потім результат множиться на 3. Отримуємо 12 * 3 = 36.

Пріоритет арифметичних операторів та порівняння

Арифметичні оператори мають вищий пріоритет, ніж оператори порівняння. Тому спочатку виконується microcosmic математичне обчислення, а потім порівняння отриманого результату.

Приклад коду
let result = 5 + 10 > 8;

console.log(result); // true
Що відбувається?

Спочатку виконується додавання: 5 + 10 = 15. Потім JavaScript порівнює 15 і 8. Оскільки 15 більше за 8, результатом буде true.

Асоціативність операторів

Якщо оператори мають однаковий пріоритет, порядок їх виконання визначається асоціативністю. Наприклад, оператори додавання та віднімання виконуються зліва направо.

Приклад коду
let result = 20 - 5 + 2;

console.log(result); // 17
Що відбувається?

Оператори віднімання та додавання мають однаковий пріоритет і виконуються зліва направо. Спочатку 20 - 5 = 15, потім 15 + 2 = 17.

Низький пріоритет оператора присвоювання (=)

Оператор присвоювання = має низький пріоритет. Спочатку JavaScript виконує обчислення у правій частині виразу, а потім присвоює отриманий результат змінній.

Приклад коду
let a = 5 + 3 * 2;

console.log(a); // 11
Що відбувається?

Спочатку виконується множення 3 * 2 = 6. Потім додавання 5 + 6 = 11. Після цього отримане значення 11 присвоюється змінній a.

Запам'ятай

Пріоритет — визначає, які оператори виконуються першими.

() — дії у дужках виконуються першими.

Асоціативність — визначає порядок виконання операторів з однаковим пріоритетом.

Арифметичні оператори — мають вищий пріоритет, ніж оператори порівняння.

= — оператор присвоювання має низький пріоритет, тому обчислення виконуються перед присвоюванням.
