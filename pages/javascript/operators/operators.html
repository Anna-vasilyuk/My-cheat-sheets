Що таке оператори?

Оператори в JavaScript — це спеціальні символи або ключові слова, які дозволяють виконувати різні дії над значеннями та змінними.

За допомогою операторів можна виконувати математичні обчислення, порівнювати значення, перевіряти умови та присвоювати значення змінним.

Види операторів

У JavaScript існує декілька основних категорій операторів. Обери потрібну тему, щоб перейти до детального пояснення.

Унарні оператори

Виконують дію з одним операндом.

Оператори порівняння

Дозволяють порівнювати два значення.

Оператори присвоєння

Дозволяють присвоювати та змінювати значення змінних.

Арифметичні оператори

Використовуються для виконання математичних обчислень.

Логічні оператори

Допомагають об'єднувати та перевіряти умови.

Умовний оператор "?"

Тернарний оператор для швидкого створення коротких умов в один рядок коду.

Порядок виконання операторів

Правила пріоритету: що JavaScript виконує в першу чергу.
