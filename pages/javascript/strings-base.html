Що таке рядок?

Рядок (String) — це примітивний тип даних у JavaScript, який використовується для представлення текстової інформації. Будь-який текст, загорнутий у лапки, комп'ютер вважає рядком (навіть число "25").

Перевірка типу:

Команда typeof "Hello" завжди повертає значення "string".

Оберіть наступний крок розширення теми, щоб дізнатися більше:

Крок 2. Доступ до символів та довжина рядка →

Вивчіть роботу з індексами рядка, використання властивості .length та найголовніше правило безпеки — незмінність рядків.

Базова операція: Об'єднання рядків (Конкатенація)

За допомогою оператора + рядки можна легко "склеювати" між собою. Якщо ви додаєте число до рядка, JavaScript автоматично перетворить число на текст.

Приклад коду
let user = "John";
let age = 25;
let message = "Hello";

// Склеюємо через плюс та додаємо пробіли з комами:
alert(user + ", " + age + ", " + message); // "John, 25, Hello"
