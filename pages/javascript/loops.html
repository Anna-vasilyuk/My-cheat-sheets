Цикли в JavaScript

Потужний інструмент для автоматичного повторення однотипних дій

← Назад до JavaScript

Основні поняття

При написанні скриптів часто постає завдання зробити однотипну дію багато разів. Наприклад, вивести товари зі списку один за одним, або просто перебрати всі числа від 1 до 5 та для кожного виконати однаковий код.

Для багаторазового повторення однієї ділянки коду передбачено цикли. Код із циклу виконується доти, доки його умова є істинною (true).

Що таке ітерація?

Одне виконання тіла циклу по-науковому називається ітерація. Наприклад, якщо цикл перебирає числа від 1 до 5, це означає, що він робить рівно п'ять ітерацій.

Три основні типи циклів

У JavaScript існує 3 базові архітектури циклів. Обери потрібний тип для детального вивчення на цій сторінці:

1. Цикл while

Цикл із передумовою. Виконує код доти, доки умова всередині дужок залишається істинною.

2. Цикл do...while

Цикл із постумовою. Спочатку гарантовано виконує тіло циклу один раз, а вже потім перевіряє умову.

3. Цикл for

Найпопулярніший цикл із лічильником. Ідеально підходить для випадків, коли кількість повторень відома заздалегідь.

1. Цикл "while" (Поки)

Це найпростіша архітектура циклу. Доки умова всередині круглих дужок є вірною (true), виконується код із тіла циклу.

Приклад коду лічильника
let i = 0;

while (i < 3) { 
  alert(i); // Спочатку показується 0, далі 1, потім 2
  i++;      // Збільшуємо лічильник на одиницю
}

🚨 Важливі особливості та пастки

1. Нескінченний цикл (Вічна петля):

If команду збільшення лічильника i++ випадково пропустити в коді вище, то умова 0 < 3 завжди залишатиметься правдою. Через це цикл виконувався б вічно.

На практиці, сучасні браузери надають способи примусово зупинити такі зациклені вкладки, а в серверному JavaScript (Node.js) ми можемо повністю знищити цей завислий процес у терміналі.

2. Будь-який вираз в умові:

Умовою циклу може бути не тільки математичне порівняння (на кшлат a < 5 або b !== 10). JavaScript дозволяє передавати туди будь-який вираз або змінну — двигун виконає їх і автоматично конвертує у логічне (булеве) значення true або false.

2. Цикл "do...while" (Роби... поки)

Перевірку умови можна розмістити під тілом циклу, використовуючи спеціальний синтаксис do...while. Головна відмінність від звичайного while полягає в тому, що перевірка відбувається **після** виконання дій.

Приклад коду з постумовою
let i = 1;

do {
  alert(i); // Послідовно покаже 1, потім 2
  i++;
} while (i < 3);

Коли виправдано синтаксис do...while?

Така forma синтаксису необхідна тоді, коли ви хочете, щоб тіло циклу обов'язково виконалося хоча б один раз, незалежно від умови (навіть якщо з самого початку умова виявиться хибною — false).

Насправді в реальній практиці форма з передумовою while (...) { ... } використовується набагато частіше, але do...while залишається незамінним інструментом для специфічних завдань (наприклад, коли треба спочатку хоча б один раз запитати дані у користувача через prompt).

3. Цикл "for" (Для)

Цикл for є більш складним за своєю структурою, але водночас він є найчастіше використовуваним циклом у JavaScript, оскільки дозволяє тримати всі налаштування лічильника в одному місці.

Приклад коду з лічильником
for (let i = 0; i < 3; i++) { 
  alert(i); // Послідовно показується 0, далі 1, потім 2
}

Анатомія та складові циклу for

Конструкція в круглих дужках розділена двома крапками з комою ; і складається з чотирьох частин:

Частина Приклад Як це працює?
Початок let i = 0; Виконується лише один раз, на самому початку під час першого входу в цикл. Створює змінну-лічильник.
Умова i < 3; Перевіряється перед кожною ітерацією циклу. Якщо умова стає невірною (false), цикл миттєво зупиняється.
Тіло alert(i); Код у фігурних дужках, який виконується знову і знову, поки умова є правдивою (true).
Крок i++ Виконується автоматично після тіла на кожній ітерації, але строго перед наступною перевіркою умови.

Загальний алгоритм роботи циклу

Покроковий конвеєр виконання всередині JavaScript працює за наступною схемою:

Початок виконання (let i = 0)
➡️ Перевірка умови (0 < 3 == true) ➡️ Виконати тіло ➡️ Виконати крок (i стає 1)
➡️ Перевірка умови (1 < 3 == true) ➡️ Виконати тіло ➡️ Виконати крок (i стає 2)
➡️ Перевірка умови (2 < 3 == true) ➡️ Виконати тіло ➡️ Виконати крок (i стає 3)
➡️ Перевірка умови (3 < 3 == false) ❌ Цикл зупинено!

Особливість: Крок циклу може бути дробовим

Крок циклу не обовʼязково має бути цілим числом. Ось приклад циклу for з кроком 1.5, де ми починаємо з 0 і збільшуємо значення на 1.5 при кожній ітерації: 

for (let i = 0; i < 10; i += 1.5) {
  console.log(i);
}

У цьому прикладі ми починаємо з i = 0 і збільшуємо i на 1.5 при кожній ітерації. Це призведе до виведення чисел: 0, 1.5, 3, 4.5, 6, 7.5, 9, до тих пір, поки i залишається меншим за 10. Крок 1.5 дозволяє нам легко переходити через значення з дробовою частиною.

4. Переривання циклу за допомогою "break"

Зазвичай цикл завершується природним шляхом, коли його умова повертає false. Проте ми можемо насильно зупинити та вийти з циклу в будь-яку мить із будь-якого рядка за допомогою спеціальної директиви break.

Приклад коду: нескінченний збір суми
let sum = 0;

while (true) {
  let value = +prompt("Введіть число", '');
  
  if (!value) break; // якщо скасовано або введено не число — виходимо
  
  sum += value;
}

alert('Сума: ' + sum);

Логіка роботи директиви break

1. Нескінченна умова true:

Конструкція while (true) створює вічний цикл, який ніколи не зупиниться сам, адже слово true завжди є істинним.

2. Точка виходу:

Рядок if (!value) break; є нашою підстраховкою. Якщо користувач натисне «Скасувати», закриє вікно або введе порожнє поле, у змінну потрапить порожнеча, логічне заперечення !value перетвориться на правду і спрацює команда break.

3. Миттєва зупинка:

Щойно JavaScript бачить команду break, він миттєво кидає виконання циклу, ігнорує рядок sum += value і відразу перестрибує на код під циклом, виводячи фінальний alert із назбираною сумою.
