Керування логікою коду: if, else, ? та switch

Як навчити програму приймати рішення на основі умов

Інструкція if (...)

Іноді нам потрібно виконувати різні дії на основі різних умов. Інструкція if (...) обчислює умову в круглих дужках і, якщо її результат дорівнює true, виконує блок коду, який йде слідом. 

let year = prompt('В якому році була опублікована ECMAScript-2015?');

if (year == 2015) {
  alert('Ви маєте рацію!');
}

Блоки «else» та «else if»

Блок else виконується тоді, коли умова в if виявилася хибною (false). Якщо ж умов декілька, ми можемо використатати ланцюжок else if. 

let year = prompt('В якому році була опублікована ECMAScript-2015?');

if (year == 2015) {
  alert('Ви здогадалися правильно!');
} else {
  alert('Як ви можете так помилятися?'); // будь-яке значення, окрім 2015
}

Умовний (тернарний) оператор '?'

Коли нам потрібно просто присвоїти змінній те чи інше значення залежно від умови, замість великої конструкції if/else краще використати короткий тернарний оператор.

Він називається "тернарним", бо працює одразу з трьома операндами: умова ? значення_якщо_true : значення_якщо_false. 

let age = prompt('Скільки вам років?');
// Скорочений запис умови в один рядок
let accessAllowed = (age >= 18) ? 'Доступ дозволено' : 'Доступ заборонено';

alert(accessAllowed);

Конструкція «switch» та групування «case»

Коли умов else if стає занадто багато, код починає виглядати громіздко. Якщо потрібно порівняти одну змінну з багатьма конкретними значеннями, використовують інструкцію switch. Вона порівнює вираз із варіантами case за допомогою строгого порівняння (===). 

let browser = prompt('Яким браузером ви користуєтеся?');

switch (browser) {
  case 'Edge':
    alert("О, у вас є Edge!");
    break;

  case 'Chrome':
  case 'Firefox':
  case 'Safari':
    alert('Так, ми підтримуємо ці браузери також');
    break;

  default:
    alert('Сподіваємося, що ваш браузер виглядає добре!');
}

Групування декількох «case»

Декілька варіантів case, що мають виконувати один і той самий код, можна групувати разом. Наприклад, виконаємо спільний код для case 3 та case 5, просто записавши їх один за одним без оператора break між ними: 

let a = prompt('Скільки буде 2 + 2?', '');

switch (+a) {
  case 4:
    alert('Вірно!');
    break;

  case 3: // (*) групуємо два блоки case
  case 5:
    alert('Невірно!');
    alert('Можливо, вам варто відвідати урок математики?');
    break;

  default:
    alert('Результат виглядає дивно. Дійсно.');
}

Запам'ятай

if (умова) — блок коду виконається тільки тоді, коли умова всередині дужок перетвориться на true.

else — відпрацьовує як підстраховка у всіх інших випадках, коли головна умова була хибною.

Тернарний оператор (?) — компактна заміна if/else, призначена суто для швидкого вибору між двома значеннями в один рядок коду.

switch / case — використовується для перевірки однієї змінної на рівність з багатьма значеннями. Не забувайте про break, щоб уникнути «провалювання» коду.
