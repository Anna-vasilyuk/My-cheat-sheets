Функція prompt() в JavaScript

Отримання текстових даних від користувача сайту

← Назад до усіх інструментів

Синтаксис функції

Функція prompt() використовується для того, щоб задати відвідувачу сайту запитання, надати поле для введення тексту та дочекатися відповіді. 

prompt(title, [default]);
  • title — текст (запитання), який буде відображатися для відвідувача.
  • default — необов'язковий другий параметр, що задає початкове (заздалегідь вписане) значення у полі введення.

Квадратні дужки [ ] у документації

У синтаксисі вище навколо параметра default стоять квадратні дужки. У технічній документації це завжди означає, що параметр є необов'язковим. Його можна просто не писати.

Що повертає виклик prompt()?

Функція завжди повертає один із двох варіантів результату:

  • Текст — якщо користувач ввів дані й натиснув "ОК" (навіть якщо рядок залишився порожнім, повернеться "").
  • null — унікальний тип даних, який повертається, якщо користувач натиснув кнопку "Скасувати" (Cancel) або закрив вікно клавішею Esc.

Практичний приклад роботи коду

Натисніть кнопку, щоб запустити вікно запиту імені та перевірити роботу логічного розгалуження в консолі й на екрані: 

let name = prompt("Будь ласка, введіть ваше ім'я:");

if (name !== null) {
  console.log(`Вас звати ${name}`);
} else {
  console.log("Ви скасували введення.");
}

Запам'ятай

prompt() — створює модальне вікно з полем введення тексту.

null — ознака того, що користувач передумав і скасував операцію.

Тип даних — усе, що користувач вводить у вікно (наприклад, число 25), автоматично повертається як рядок (String). Для математичних розрахунків цей результат доведеться перетворювати на число.
