Функція confirm() в JavaScript

Отримання логічного підтвердження від користувача сайту

← Назад до усіх інструментів

Синтаксис функції

Функція confirm() використовується для того, щоб задати відвідувачу сайту запитання, яке потребує однозначної відповіді: згоди чи відмови. 

confirm(question);
  • question — текст запитання, яке відображається у модальному вікні.

Функція показує вікно з цим запитанням та двома кнопками: ОК та Скасувати (Cancel).

Логічний результат роботи

На відміну від prompt(), який повертає текст, функція confirm() повертає виключно булеве (логічне) значення:

  • true (істина) — якщо користувач натиснув кнопку ОК.
  • false (хибність) — якщо користувач натиснув кнопку Скасувати або закрив вікно клавішею Esc.

Практичний приклад роботи коду

Натисніть кнопку, щоб запустити перевірку статусу та побачити результат на екрані: 

let isBoss = confirm("Ви бос?");

alert(isBoss); // виведе true, якщо натиснуто ОК, інакше — false

Запам'ятай

confirm() — ідеальний інструмент для підтвердження важливих або небезпечних дій на сайті (наприклад: "Ви дійсно хочете видалити цей файл?").

Булевий тип даних — результат роботи цієї функції завжди є або true, або false, що дозволяє легко використовувати її в умовах if / else.

Модальність — вікно повністю блокує сторінку, поки користувач не обере один із варіантів.
