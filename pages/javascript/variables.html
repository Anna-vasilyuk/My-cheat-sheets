Змінні

Зберігання даних у JavaScript

Що таке змінна?

Змінна — це іменоване сховище для даних. Ми можемо використовувати змінні для зберігання товарів, відвідувачів та іншої інформації.

Створення змінної

Для створення змінних у JavaScript використовують три ключові слова: var, let, const.

Оголошення змінної

Наприклад, створимо змінну з ім'ям name:

var name;

Присвоєння значення

Щоб записати дані у змінну, використовують оператор присвоєння =. 

var Surname = "John";

console.log(Surname); // Виведе "John"

Способи оголошення змінних

var

Старий спосіб

Значення можна змінювати та повторно оголошувати.

var name = "John";
name = "Anna";

let

Сучасний спосіб

Значення можна змінювати, але не можна повторно оголошувати в тій самій області видимості. 

let age = 25;
age = 30;

const

Константа

Значення не можна переприсвоїти. Його потрібно задати одразу.

const pi = 3.14;

1. Тип змінної — var

Ключове слово var було першим способом оголошення змінних у JavaScript.

Змінні, оголошені за допомогою var, мають глобальну або функціональну область видимості залежно від місця оголошення.

Приклад:

var name = "John";

console.log(name); // John

Значення змінної можна змінювати, а також повторно оголошувати її з тим самим ім'ям у тій самій області видимості. 

var name = "John";
var name = "Anna";

console.log(name); // Anna

Однак var має особливості області видимості, які можуть призводити до небажаних результатів.

2. Тип змінної — let

Ключове слово let було введене у стандарті ECMAScript 6 (ES6) у 2015 році.

Змінні let мають блочну область видимості. Це означає, що вони доступні лише всередині блоку коду, в якому були оголошені.

Приклад:

let age = 30;

if (true) {
    let age = 25;
    console.log(age); // 25
}

console.log(age); // 30

Використання let допомагає уникати конфліктів імен змінних та робить код зрозумілішим.

3. Тип змінної — const

Ключове слово const також було введене у стандарті ES6.

Воно використовується для оголошення змінних, яким не можна переприсвоїти інше значення.

Змінна const має блочну область видимості та обов'язково повинна отримати значення під час оголошення.

Приклад:

const pi = 3.14;

console.log(pi); // 3.14

Якщо спробувати переприсвоїти значення const, JavaScript видасть помилку. 

const pi = 3.14;

pi = 5; // TypeError

Якщо програміст знає, що змінній не потрібно переприсвоювати значення, варто використовувати const.

Порівняння var, let та const

Розглянемо основні відмінності між трьома способами оголошення змінних.

Особливість var let const
Зміна значення Так Так Ні
Повторне оголошення в тій самій області Так Ні Ні
Обов'язкове початкове значення Ні Ні Так
Блочна область видимості Ні Так Так

Області видимості та Hoisting (Простими словами)

Що таке область видимості?

Область видимості — це "прописка" або кордони, всередині яких змінна має право перебувати. За межами цих кордонів програми її просто не існує.

Змінна var безвідповідальна і може проходити крізь стіни фігурних дужок {}. А от let і const суворо зачиняються всередині того блоку (бункера), де їх було створено.

Приклад із var (Проходить крізь стіни)

if (true) {
    var first = "Я var"; // Змінна зайшла всередину блоку {}
}

console.log(first); // Виведе: "Я var" (Спокійно вийшла назовні)

Приклад із let (Зачинена в бункері)

if (true) {
    let second = "Я let"; // Народилася всередині блоку {}
} // <--- Блок зачинився, змінна миттєво зникла з пам'яті!

console.log(second); // Помилка: ReferenceError (Для програми її більше немає)

Що таке Hoisting?

Hoisting (підняття) — це особливість JavaScript, коли перед виконанням коду інтерпретатор (як Режисер перед виставою) спочатку пробігається по сценарію і заздалегідь виділяє кімнати для всіх змінних. Але з var та let він поводиться по-різному.

Приклад із var (Доброзичливий привид):

console.log(first); // Виведе: undefined (Кімната вже є, але костюм "Hello" ще не видали)

var first = "Hello";

Приклад із let (Суворий охоронець та TDZ):

console.log(second); // Помилка: ReferenceError (Доступ заблоковано охоронцем!)

let second = "Hello";

Змінні let і const Режисер теж бачить заздалегідь, але вішає на їхні двері замок, поки код не дійде до рядка оголошення. Цей період заборони називається TDZ (Тимчасова мертва зона). Заглядати туди завчасно не можна — програма зламається.

Підсумок (Правила розробника)

  • const — залізобетонний сейф. Використовуй за замовчуванням для всього, що не плануєш змінювати.
  • let — гнучка коробка. Використовуй лише тоді, коли значення змінної точно буде перезаписуватися (наприклад, лічильник у циклах).
  • var — старий "привид" із минулого. Має купу прихованих багів через ігнорування блоків та підняття. У сучасному коді не використовується.

Завжди називай змінні латиницею. Якщо ім'я складається з декількох слів, зшивай їх за правилом горбів верблюда — camelCase (перше слово з маленької літери, всі наступні — з великої): 

let userName;         // Правильно
let myFirstVariable;  // Читиабельно
const siteTitle;      // Зрозуміло

Оголошення декількох змінних

Кожну змінну можна оголосити з нового рядка:

let user = "John";
let age = 25;
let message = "Hello";

Змінна — аналогія з життя

JavaScript — це динамічно типізована мова програмування. Це означає, що змінна може зберігати дані різних типів під час виконання програми.

Щоб краще зрозуміти поняття змінної, уявімо її у вигляді коробки для даних з унікальною назвою на наклейці.

Ми можемо покласти значення в коробку, а потім змінювати його стільки разів, скільки потрібно.

Приклад

let message;

message = "Привіт!";
message = "Світ!";

alert(message);

У цьому прикладі спочатку змінна message отримує значення "Привіт!", а потім воно змінюється на "Світ!".

Команда alert() показує повідомлення у вікні браузера.

Іменування змінних

У JavaScript є декілька правил, яких потрібно дотримуватися під час створення імен змінних:

1. Ім'я може містити букви, цифри, символи $ та _.

2. Ім'я не може починатися з цифри.

Приклади правильних імен

let userName;
let test123;
let _name;
let $price;

Верблюжий регістр (camelCase)

Якщо ім'я змінної складається з декількох слів, зазвичай використовують camelCase.

Слова пишуться разом, без пробілів, а кожне наступне слово починається з великої букви. Перше слово пишеться з маленької букви. 

let myVeryLongName;

Детальніше про верблюжий регістр .

Символи $ та _

Символи долара ($) та підкреслення (_) також можна використовувати в іменах змінних. 

let $ = 1;
let _ = 2;

alert($ + _); // Виведе 3

Регістр та нелатинські символи

Регістр має значення

Змінні з іменами apple та APPLE — це дві різні змінні. JavaScript розрізняє великі та маленькі літери. 

let apple = "apple";
let APPLE = "APPLE";

alert(apple);
alert(APPLE);

Нелатинські букви

У JavaScript можна використовувати літери різних мов, зокрема українські та китайські. Але зазвичай рекомендується використовувати латиницю, щоб код було легше читати іншим програмістам. 

let назва = "Мій сайт";
let 你好 = "Привіт!";

Зарезервовані слова

У JavaScript є список зарезервованих слів, які не можна використовувати як імена змінних, тому що ці слова вже використовуються самою мовою.

Наприклад: let, class, return, function — це зарезервовані слова.

Приклади неправильного коду

let let = 5;       // Помилка
let return = 5;    // Помилка
let class = 10;    // Помилка

Такий код викличе синтаксичну помилку (SyntaxError), оскільки зарезервовані слова не можна використовувати як назви змінних.

Як правильно?

Замість зарезервованих слів використовуй інші назви:

let userName = "Anna";
let result = 5;
let myClass = "JavaScript";

Детальніше можна прочитати в документації MDN про ключові слова JavaScript .
