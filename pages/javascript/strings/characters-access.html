Доступ до символів та довжина рядка

У JavaScript можна отримати окремий символ рядка за його індексом, а також дізнатися, скільки символів міститься в рядку.

1. Доступ до символів рядка

Щоб отримати потрібний символ, використовують квадратні дужки та індекс символу. Важливо пам'ятати, що індексація починається з нуля.

Приклад:

let str = 'I am string';

console.log(str[0]); // I
console.log(str[1]); // пробіл
console.log(str[2]); // a

2. Довжина рядка — length

Властивість length дозволяє дізнатися кількість символів у рядку. Для її використання після назви змінної ставлять крапку та слово length.

Приклад:

let str = 'I am string';

console.log(str.length); // 11

3. Незмінність рядків

Рядки в JavaScript є незмінними (immutable). Це означає, що після створення рядка не можна змінити окремий символ безпосередньо за його індексом.

Приклад:

let str = 'Hi';

str[0] = 'h';

console.log(str); // Hi

Присвоєння нового значення символу не змінює початковий рядок. У строгому режимі така спроба спричинить помилку TypeError.

Запам'ятай

  • str[0] — отримання першого символу рядка.
  • Індексація символів починається з нуля.
  • str.length — кількість символів у рядку.
  • Рядки в JavaScript незмінні.
  • Щоб отримати змінений рядок, потрібно створити новий рядок.
