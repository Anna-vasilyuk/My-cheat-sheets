Вивчення методу рядків .replace()

Як замінити частину тексту?

Для пошуку та заміни певного слова або фрагмента тексту у JavaScript використовується вбудований метод .replace(). Він приймає два значення: що саме шукати та на що його замінити.

Використання методу .replace()

Метод шукає вказане слово й створює на його основі новий текст. Нагадуємо, що рядки є незмінними, тому початкова змінна завжди залишається у своєму оригінальному стані.

Приклад коду
let str = "Please visit Microsoft!";

// Створюємо новий рядок із заміною
let n = str.replace("Microsoft", "W3Schools");

console.log(n);   // "Please visit W3Schools!"
console.log(str); // "Please visit Microsoft!" (оригінал не змінився)

🚨 Що варто враховувати?

1. Регістрозалежність:

Метод .replace() чутливий до великих і маленьких літер. Якщо ви спробуєте виконати str.replace("microsoft", "W3Schools") (з маленької літери "m"), JavaScript просто не знайде це слово й поверне текст без змін.

2. Заміна лише першого збігу:

Якщо слово зустрічається в тексті кілька разів, метод .replace() замінить **тільки перше** знайдене слово. Для заміни всіх копій у сучасному JavaScript використовують метод .replaceAll() або регулярні вирази.

Запам'ятай

str.replace(що_шукаємо, на_що_міняємо) — метод для створення копії рядка з оновленим фрагментом.

Оригінал не змінюється — робота методу ще раз доводить правило незмінності типу даних String.

Регістр має значення — слова "Microsoft" та "microsoft" для цього методу є абсолютно різними.
