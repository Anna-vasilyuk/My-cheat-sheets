Метод substring()

Метод substring() повертає частину рядка, починаючи з указаного індексу. Початкова позиція включається, а кінцева — не включається.

1. Синтаксис методу substring()

Синтаксис:

str.substring(start, end);

start — індекс, з якого починається підрядок.
end — індекс, на якому підрядок закінчується (цей символ уже не включається).

Якщо параметр end не вказати, метод поверне всі символи від start до кінця рядка.

2. Приклади використання

Приклад:

let str = "stringify";

console.log(str.substring(0, 1)); // "s"
console.log(str.substring(2, 6)); // "ring"

У першому прикладі отримуємо символ з індексом 0. У другому — символи з індексами 2, 3, 4 та 5. Символ з індексом 6 не включається.

3. Отримання підрядка до кінця рядка

Приклад:

let str = "stringify";

console.log(str.substring(2)); // "ringify"

Якщо вказати лише початковий індекс, метод поверне всі символи від цієї позиції до кінця рядка.

Запам'ятай

  • substring(start, end) повертає частину рядка.
  • start — початковий індекс, він включається.
  • end — кінцевий індекс, він не включається.
  • Якщо end не вказано, підрядок береться до кінця рядка.
  • Метод substring() не змінює початковий рядок.
