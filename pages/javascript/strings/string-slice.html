Метод slice()

Метод slice() витягує частину рядка та повертає її у вигляді нового рядка. Початковий рядок при цьому не змінюється.

1. Синтаксис методу slice()

Синтаксис:

str.slice(start, end);

start — індекс, з якого починається витягування частини рядка.
end — індекс, до якого витягується рядок, але сам символ із цим індексом не включається.

Якщо параметр end не вказати, метод поверне всі символи від start до кінця рядка.

2. Витягування частини рядка

Приклад:

let str = "Please visit Microsoft!";

console.log(str.slice(5));
// "e visit Microsoft!"

console.log(str.slice(5, 6));
// "e"

У першому прикладі метод повертає всі символи, починаючи з індексу 5 і до кінця рядка.
У другому прикладі повертається лише один символ з індексом 5, оскільки символ з індексом 6 не включається.

3. Використання від'ємних індексів

Метод slice() також підтримує від'ємні індекси. Вони рахуються з кінця рядка. Наприклад, індекс -1 означає останній символ.

Приклад:

let str = "JavaScript";

console.log(str.slice(-6)); // "Script"
console.log(str.slice(-6, -3)); // "Scr"

Запам'ятай

  • slice(start, end) витягує частину рядка.
  • start — початковий індекс, він включається.
  • end — кінцевий індекс, він не включається.
  • Якщо end не вказано, рядок витягується до кінця.
  • Можна використовувати від'ємні індекси.
  • Метод slice() не змінює початковий рядок.
