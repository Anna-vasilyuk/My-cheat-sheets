Що таке шаблонні рядки?

Шаблонні рядки — це зручний спосіб створення та форматування рядків у JavaScript. Вони дозволяють вставляти значення змінних, виконувати вирази безпосередньо всередині рядка та створювати багаторядковий текст.

Головна особливість шаблонних рядків — використання зворотних лапок (` `) замість звичайних одинарних або подвійних лапок.

Синтаксис шаблонних рядків

Шаблонні рядки записуються за допомогою зворотних лапок. Для вставлення змінних та виразів використовуються спеціальні конструкції ${...}.

Приклад коду
const name = "John";

const greeting = `Привіт, ${name}!`;

console.log(greeting); // Привіт, John!
Що відбувається?

Створюється змінна name зі значенням John. Усередині шаблонного рядка за допомогою ${name} вставляється значення цієї змінної. У результаті отримуємо рядок "Привіт, John!".

Вставлення виразів у шаблонні рядки

За допомогою ${...} можна вставляти не лише змінні, а й математичні вирази та результати обчислень.

Приклад коду
const a = 10;
const b = 5;

const result = `Сума чисел: ${a + b}`;

console.log(result); // Сума чисел: 15
Що відбувається?

Усередині шаблонного рядка записаний вираз ${a + b}. JavaScript спочатку обчислює суму чисел 10 і 5, а потім вставляє результат 15 у рядок.

Багаторядковий текст

Шаблонні рядки дозволяють створювати текст, який займає декілька рядків. Для цього достатньо записати текст між зворотними лапками та перейти на новий рядок. Використовувати спеціальний символ \n не потрібно.

Приклад коду
const best = `
Думи мої, думи мої,
Лихо мені з вами!
Нащо стали на папері
Сумними рядами?..`;

console.log(best);
Що відбувається?

У змінній best зберігається багаторядковий текст. Переноси рядків зберігаються автоматично. Під час виведення через console.log текст відображається у тому самому форматі, у якому його було записано.

Звичайні рядки та шаблонні рядки

Звичайні рядки створюються за допомогою одинарних або подвійних лапок. Шаблонні рядки використовують зворотні лапки та дозволяють вставляти значення змінних без додаткового об'єднання.

Звичайний рядок
const name = "John";

const greeting = "Привіт, " + name + "!";

console.log(greeting);
Шаблонний рядок
const name = "John";

const greeting = `Привіт, ${name}!`;

console.log(greeting);
У чому різниця?

Обидва приклади дають однаковий результат. Проте шаблонний рядок робить код коротшим і зрозумілішим, особливо коли потрібно вставити декілька змінних.

Запам'ятай

` ` — зворотні лапки, які використовуються для створення шаблонних рядків.

${...} — конструкція для вставлення змінних та виразів у рядок.

Багаторядковість — можливість записувати текст у декілька рядків без використання \n.

Шаблонні рядки — спрощують створення та форматування тексту в JavaScript.
