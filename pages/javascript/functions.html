Функції в JavaScript

← Назад до JavaScript

Що таке функції?

Під час написання програми часто виникає потреба виконувати одну й ту саму дію в різних її частинах.

Наприклад, сайт може виводити повідомлення, коли відвідувач заходить на сторінку, виходить із неї або виконує певну дію.

У чому проблема?

Якщо щоразу писати однаковий код заново, програма стає довшою, а підтримувати її складніше.

Рішення — функції

Функція (Function) — це окремий блок коду, який можна створити один раз, а потім викликати тоді, коли потрібно виконати певну дію.

Уяви функцію як інструкцію:

Ти один раз пояснюєш, що потрібно зробити, а потім можеш попросити виконати цю інструкцію знову.

Вбудовані функції JavaScript

У JavaScript уже є готові функції, які ми можемо використовувати без самостійного створення.

alert(message) Виводить повідомлення у спливаючому вікні браузера.
prompt(message, default) Відкриває вікно, у якому користувач може ввести дані.
confirm(question) Запитує підтвердження дії за допомогою кнопок OK та Cancel.
Приклади вбудованих функцій
alert("Привіт!");

let name = prompt("Як тебе звати?");

let answer = confirm("Продовжити?");
Що потрібно зрозуміти?

alert(), prompt() та confirm() — це вже готові функції. Ми лише викликаємо їх і передаємо потрібні значення.

Власні функції

Окрім готових функцій, JavaScript дозволяє створювати власні. Ми самостійно визначаємо, які дії вони будуть виконувати.

Головне, що потрібно запам'ятати:

Функція допомагає уникати повторення однакового коду та повторно використовувати вже написані інструкції.

Оголошення функції

У JavaScript є два основні способи створення функцій: Function Declaration та Function Expression.

Function Declaration

Функція оголошується за допомогою ключового слова function. 

function showName() {
  console.log('My name');
}

Function Expression

Функція створюється та записується у змінну.

let showName = function() {
  console.log('My name');
};
У чому різниця?

Головна відмінність полягає в тому, що Function Declaration можна викликати ще до місця її оголошення в коді. JavaScript обробляє такі оголошення до виконання коду.

Виклик до оголошення

showName();

function showName() {
  console.log('My name');
}

Цей приклад працює: у консолі з'явиться повідомлення My name.

А що з Function Expression?

showName();

let showName = function() {
  console.log('My name');
};

Такий код викличе помилку, тому що змінна ще не отримала значення функції на момент виклику.

Запам'ятай:
  • Function Declaration — функцію можна викликати до її оголошення.
  • Function Expression — спочатку потрібно створити функцію та присвоїти її змінній, а вже потім викликати.

Область видимості (Scope)

Область видимості визначає, звідки в програмі можна отримати доступ до змінної.

1. Змінні всередині функції

Змінні, оголошені всередині функції, доступні лише в межах цієї функції. Ззовні звернутися до них не можна. 

function showName() {
  let message = 'My name';

  console.log(message);
}

showName(); // My name

console.log(message); // Error
Чому виникає помилка?

Змінна message створена всередині функції showName(). Тому вона існує лише в її області видимості. Після завершення функції звернутися до неї ззовні не можна.

2. Доступ до зовнішніх змінних

Функція може використовувати змінні, які оголошені за її межами.

let name = 'Anton';

function showName() {
  let message = `Hi, ${name}`;

  console.log(message);
}

showName(); // Hi, Anton
Чому це працює?

Змінна name оголошена зовні функції. Функція showName() має доступ до неї, тому може використовувати її всередині свого коду.

Запам'ятай:
  • Внутрішні змінні доступні лише всередині своєї функції.
  • Функція може звертатися до зовнішніх змінних.
  • Зовнішній код не може звертатися до локальних змінних функції.

Зміна зовнішніх змінних

Функція має повний доступ до зовнішніх змінних і може не лише читати їх, але й змінювати їхні значення. 

let userName = 'Іван';

function showMessage() {
  userName = "Богдан"; // Змінюємо значення зовнішньої змінної
  let message = 'Здоровенькі були, ' + userName;
  alert(message);
}

alert(userName); // Іван (до виклику функції)

showMessage();   // Викличе вікно з текстом: "Здоровенькі були, Богдан"

alert(userName); // Богдан (значення змінилося назавжди)
Зверніть увагу:

Якщо всередині функції змінна перевизначається без ключових слів let або const (як у рядку userName = "Богдан"), JavaScript шукає її ззовні та перезаписує глобальне значення.

Перекриття (затінення) зовнішніх змінних

Зовнішня змінна використовується функцією тільки тоді, коли всередині функції немає однойменної локальної змінної.

Якщо змінна з таким самим ім'ям оголошується всередині функції через let або const, вона перекриває (затінює) зовнішню змінну. Зовнішню буде проігноровано. 

let userName = 'Іван'; // Оголошення зовнішньої змінної

function showMessage() {
  let userName = "Богдан"; // Оголошення локальної змінної (вона перекриває зовнішню)
  let message = 'Привіт, ' + userName; // Використає "Богдан"
  alert(message);
}

// Функція завжди віддасть перевагу локальним змінним
showMessage(); // Виведе вікно: "Привіт, Богдан"

alert(userName); // Іван (значення зовнішньої змінної залишилося без змін)
У чому головна фішка?

Оскільки всередині функції було використано ключове слово let userName, JavaScript створив абсолютно нову, локальну змінну. Вона живе тільки всередині функції і ніяк не впливає на зовнішню змінну userName, яка залишилася зовні.

Аргументи функції

Ми можемо передати всередину функції будь-яку інформацію, використовуючи параметри та аргументи виклику.

У наведеному нижче прикладі функції передаються два параметри: from і text. 

function showMessage(from, text) { // параметри: from, text
  alert(from + ': ' + text);
}

showMessage('Анна', 'Привіт!'); // Анна: Привіт! (*)
showMessage('Анна', 'Як справи?'); // Анна: Як справи? (**)
Як це працює?

Надіслані значення під час виклику копіюються в локальні змінні from і text. Потім вони використовуються всередині тіла функції.

Аргументи за замовчуванням

Якщо параметр не вказано під час виклику функції, його значенням автоматично стає undefined.

Наприклад, вищезазначена функція showMessage(from, text) може бути викликана лише з одним аргументом: showMessage('Анна');. Це не призведе до помилки, але такий виклик виведе "Анна: undefined", оскільки параметр text не було передано.

Рішення — значення за замовчуванням:

Щоб уникнути появи undefined, ми можемо вказати значення за замовчуванням прямо при оголошенні функції за допомогою знака рівності =. 

function showMessage(from, text = "текст не задано") {
  alert( from + ": " + text );
}

showMessage("Анна"); // Анна: текст не задано
Важливий нюанс:

Значення за замовчуванням спрацьовує лише в тому випадку, якщо аргумент взагалі не передали, або якщо замість нього передали значення undefined.

Повернення значення

Функція може повернути результат, який буде переданий у код, що її викликав.

Найпростішим прикладом може бути функція складання двох чисел:

function sum(a, b) {
  return a + b;
}

let result = sum(1, 2);
alert( result ); // 3
Як працює директива return?

Директива return може знаходитись у будь-якому місці тіла функції. Як тільки виконання коду доходить до цього місця, функція миттєво зупиняється, і значення повертається в код, що викликав її (наприклад, присвоюється змінній result).

Кілька викликів return

Усередині однієї функції директива return може використовуватися кілька разів, наприклад, у різних гілках розгалуження if...else. 

function checkAge(age) {
  if (age >= 18) {
    return true;
  } else {
    return confirm('У вас є дозвіл ваших батьків?');
  }
}

let age = prompt('Скільки вам років?', 18);

if ( checkAge(Number(age)) ) {
  alert( "Доступ надано" );
} else {
  alert( "У доступі відмовлено" );
}
Як це працює?
  • Введене користувачем значення ми обов'язково приводимо до числа за допомогою Number(age).
  • Якщо перша умова age >= 18 виконується, функція відразу повертає true і миттєво припиняє роботу, ігноруючи блок else.
  • Якщо умова хибна (користувачу менше 18), спрацьовує другий return, який передає результат вікна confirm.

Функція без значення, що повертається

Результат функції з порожнім return або взагалі без нього — завжди undefined.

Якщо функція не має директиви return, вона все одно повертає результат, як тільки доходить до кінця свого тіла. 

function doNothing() { /* порожньо */ }

alert( doNothing() === undefined ); // true

Використання порожнього оператора return повністю аналогічне запису return undefined: 

function doNothing() {
  return;
}

alert( doNothing() === undefined ); // true
Запам'ятай:

Будь-яка функція в JavaScript завжди щось повертає. Якщо ви не вказали конкретне значення за допомогою return, рушій мови автоматично підставить туди undefined.

Вибір імені функції

Функція — це дія. Тому імʼя функції зазвичай є дієсловом. Воно повинно бути коротким, точним і описувати те, що саме робить функція, щоб інший розробник міг легко зрозуміти код.

У середовищі розробників прийнято використовувати спеціальні префікси (дієслова-приставки) на початку імені, які задають характер дії:

"get..." Повертає певне значення (отримує або обчислює його).
"calc..." Щось обчислює математично та віддає результат.
"create..." Щось створює (наприклад, елемент інтерфейсу).
"check..." Перевіряє умову і зазвичай повертає булеве значення (true/false).

Приклади префіксів у коді

showMessage(...)     // Показує повідомлення
getAge(...)          // Повертає вік (отримує його)
calcSum(...)         // Обчислює суму і повертає результат
createForm(...)      // Створює HTML-форму і повертає її
checkPermission(...) // Перевіряє доступ, повертає true або false
Головне правило розробника:

Завдяки правильним префіксам, навіть при першому погляді на назву функції стає абсолютно зрозумілим, що саме робить її код та яке значення вона може повернути. Одна функція повинна робити рівно одну дію.

Чисті функції (Pure Functions)

Чистою (Pure Function) називається функція, яка завжди повертає однаковий результат, якщо вона викликається з тим самим набором аргументів. Крім того, вона не має побічних ефектів (side effects).

Що означає "немає побічних ефектів"?

Це означає, що всередині свого коду функція:

  • Не мутує (не змінює) вхідні параметри.
  • Не викликає інші функції, які можуть мутувати вхідні параметри.
  • Не робить HTTP-запитів (AJAX / fetch).
  • Не робить жодних змін у файловій системі.
  • Не робить запитів до DOM-елементів (не змінює інтерфейс сторінки).

Приклад чистої та нечистої функції

// Чиста функція — результат залежить тільки від аргументів
const addPure = (x, y) => x + y;
console.log(addPure(2, 4)); // Завжди виведе 6
console.log(addPure(2, 4)); // Знову виведе 6 (результат стабільний)

// Нечиста функція — змінює зовнішню змінну (побічний ефект)
let globalValue = 2;
const addImpure = (y) => globalValue += y;

console.log(addImpure(4)); // Виведе 6 (globalValue тепер став 6)
console.log(addImpure(4)); // Виведе 10 (результат змінився, функція нечиста!)
Чому це важливо?
  • Чисті функції легко тестувати, оскільки їхній результат є передбачуваним.
  • Вони не створюють прихованих багів, бо ніяк не впливають на інший код у програмі.

Функції вищого порядку / Функція-коллбек

Функцією вищого порядку (Higher-Order Function) називається така функція, яка приймає іншу функцію як аргумент або повертає функцію у вигляді вихідного значення.

Припустимо, у нас є масив чисел, і ми хочемо створити новий масив, який містить результати множення цих чисел на 2. Розглянемо два способи розвʼязання цього завдання: класичний (через цикл) та сучасний (з використанням функції вищого порядку).

Спосіб 1: Без функцій вищого порядку

Використовуємо звичайний цикл for та ручне наповнення масиву: 

const arr1 =;
const arr2 = [];

for (let i = 0; i < arr1.length; i++) {
  arr2.push(arr1[i] * 2);
}

// Виводить у консоль: [2, 4, 6]
console.log(arr2);

Спосіб 2: З функцією вищого порядку

Використовуємо вбудований метод масиву map(), який приймає у себе функцію: 

const arr1 =;

const arr2 = arr1.map(function(item) {
  return item * 2;
});

// Виводить у консоль: [2, 4, 6]
console.log(arr2);
Що таке колбек-функція?

Колбек-функція (Callback function / функція зворотного виклику) — це функція, яка передається в іншу функцію як аргумент, і потім викликається всередині неї після завершення певної дії.

У Способі 2 анонімна функція function(item) { return item * 2; } є саме колбеком, а метод map() — функцією вищого порядку.

IIFE — функція, що самовикликається

IIFE (Immediately Invoked Function Expression) — це функція в JavaScript, яка виконується автоматично та відразу після того, як вона була визначена в коді.

Для створення такої функції її тіло огортають у круглі дужки ( ), а наприкінці ставлять ще одні круглі дужки (), які її безпосередньо викликають. 

(function () {
  const res = 1 + 2;
  console.log(res); // Виведе 3 відразу при завантаженні сторінки
})();
Навіщо це потрібно?

Головна мета IIFE — створити **ізольовану область видимості**. Будь-які змінні, створені всередині IIFE (наприклад, const res), не засмічують глобальну область і до них не можна отримати доступ ззовні. Це дуже допомагало розробникам до появи сучасних модулів.

Вкладені функції (Nested Functions)

У JavaScript функція може бути оголошена всередині іншої функції. Таку функцію називають вкладеною (внутрішньою).

Внутрішня функція має повний доступ до змінних батьківської (зовнішньої) функції. Однак зовнішній код не має доступу до самої внутрішньої функції — вона схована від усього світу. 

function init() {
  let name = 'Test'; // Локальна змінна батьківської функції

  function displayName() { // Внутрішня функція
    alert(name); // Використовуємо змінну, яку оголосили у батьківській функції
  }

  displayName(); // Працює, бо викликається всередині батьківської функції
}

init(); // Виведе вікно: "Test"

displayName(); // Помилка! ReferenceError: displayName is not defined
Важливі правила видимості:
  • Внутрішня функція displayName() бачить і може використовувати змінну name.
  • Викликати displayName() можна тільки всередині функції init().
  • Спроба викликати внутрішню функцію з глобального коду призведе до помилки, оскільки ззовні її просто не існує.

Замикання (Closures)

Замикання (Closure) — це функція, яка має доступ до області видимості своєї зовнішньої (батьківської) функції, навіть після того, як зовнішня функція завершила своє виконання.

Це означає, що замикання може «запамʼятовувати» та отримувати доступ до змінних та аргументів своєї зовнішньої функції навіть тоді, коли та вже повністю припинила роботу й очистила свій стек. 

function person() {
  let value = 'Peter';

  return function displayName() {
    console.log(value);
  };
}

let peter = person(); // Функція person виконалась і повернула внутрішню функцію

peter(); // Виведе у консоль: 'Peter' (Внутрішня функція запам'ятала змінну value!)

console.log(value); // Помилка! ReferenceError: value is not defined
Як це працює і чому це магія?

Коли ми викликаємо person(), вона створює локальну змінну value і повертає функцію displayName. Зазвичай, коли функція завершується, її локальні змінні видаляються з пам'яті.

Але функція peter() (яка насправді є посиланням на displayName) утворює замикання. Вона тримає «живе» посилання на область видимості, в якій була створена, тому змінна value = 'Peter' продовжує існувати всередині неї.

Стрілочні функції (Arrow Functions)

У JavaScript існує ще більш простий та короткий синтаксис для створення функцій, який часто є зручнішим та лаконічнішим, ніж звичний Function Expression: 

// Звичайний синтаксис
let sum = function(a, b) {
  return a + b;
};
console.log(sum(1, 2)); // 3

Він називається "функції-стрілки" або "стрілочні функції" (arrow functions) і виглядає наступним чином: 

// Сучасний стрілочний синтаксис
let sum = (a, b) => a + b;
console.log(sum(1, 2)); // 3

Правила роботи з аргументами:

  • Зазвичай параметри завжди поміщаються всередину круглих дужок: (a, b) => a + b.
  • Якщо необхідно передати функції всього один параметр, круглі дужки можна не використовувати: const f = x => x * 2;. Проте, щоб уникнути непорозумінь та підтримувати код чистим, рекомендується завжди писати дужки: const f = (x) => x * 2;
  • Якщо параметри взагалі не потрібні, круглі дужки залишаються порожніми: const f = () => 42;

Тіло функції та повернення значення

У разі, коли необхідно виконати лише одну інструкцію (як у прикладах вище), досить просто вказати її після стрілки. Функція автоматично поверне результат цього виразу без слова return: 

const add = (a, b) => a + b; // Автоматично поверне a + b

У ситуаціях, коли однієї інструкції виявляється замало, тіло функції необхідно укласти у фігурні дужки { ... }. У такому випадку ключове слово return стає обов'язковим, інакше функція поверне undefined: 

const calcPower = (a, b) => {
  let result = Math.pow(a, b);
  return result; // Фігурні дужки вимагають явного return!
};
Критичне обмеження: розриви рядків

Стрілочна функція не може містити перенесення рядка між параметрами та самою стрілкою =>. Такий запис зламає програму: 

const func = ()
  => 1; 
// Помилка! SyntaxError: expected expression, got '=>'

Головна технічна відмінність: відсутність `arguments`

У стрілочних функцій немає вбудованого об'єкта arguments, який зберігає всі передані параметри. Спроба звернутися до нього всередині стрілки викликає помилку.

Якщо вам потрібен доступ до всіх аргументів у стрілочній функції, використовуйте сучасний **оператор rest (...args)**:

Тип функції / Синтаксис Результат спроби прочитати arguments
Звичайна функція (ES5)
init: function(a,b) { console.log(arguments) } 		Успішно — виводить повний список переданих аргументів.
Стрілочна функція (ES6)
init2: (a,b) => { console.log(arguments) } 		Помилка! ReferenceError: arguments is not defined.
Стрілочна + rest (ES6+)
init3: (a,b,...args) => { console.log(args) } 		Успішно — збирає залишок аргументів у реальний масив args.

Рекурсія (Recursion)

Рекурсія — це термін у програмуванні, що означає виклик функцією самої себе. Рекурсивні функції дозволяють елегантно та коротко вирішувати певні класи завдань, розбиваючи велику проблему на простіші підзадачі.

Жарт про рекурсію:

Щоб зрозуміти рекурсію, потрібно спочатку зрозуміти рекурсію. 🌀

Два золоті правила рекурсії:

  • Базовий випадок (Base Case): Кожна рекурсивна функція повинна мати один або кілька базових випадків, для яких не потрібно викликати саму себе. Він забезпечує зупинку рекурсії та визначає кінцевий результат (вихід із циклу викликів).
  • Рекурсивний виклик (Recursive Call): Функція повинна викликати саму себе зі зміненими параметрами, які прогресивно наближають її до базового випадку.

Приклад 1: Обчислення Факторіала

Функція factorial(n) обчислює факторіал числа n (добуток усіх чисел від 1 до n), використовуючи рекурсію: 

function factorial(n) {
  // 1. Базовий випадок: якщо n = 0, факторіал дорівнює 1
  if (n === 0) {
    return 1;
  } else {
    // 2. Рекурсивний виклик: n! = n * (n - 1)!
    return n * factorial(n - 1);
  }
}

const result = factorial(5); // Результат: 5! = 120

Два способи мислення (Ітерація vs Рекурсія)

Як приклад вивчимо функцію pow(x, n), яка зводить число x у натуральний ступінь n (множить x на себе n разів). Наприклад: pow(2, 3) // 8 або pow(2, 4) // 16.

1. Ітеративне мислення (Цикл for)

Програма послідовно множить результат у циклі:

function pow(x, n) {
  let result = 1;
  for (let i = 0; i < n; i++) {
    result *= x;
  }
  return result;
}

alert( pow(2, 3) ); // 8

2. Рекурсивне мислення (Виклик себе)

Завдання спрощується до формули x * pow(x, n - 1): 

function pow(x, n) {
  if (n == 1) {
    return x;
  } else {
    return x * pow(x, n - 1);
  }
}

alert( pow(2, 3) ); // 8
Що відбувається під капотом рекурсії?

Коли викликається pow(2, 3), комп'ютер запам'ятовує поточний стан у стек викликів (execution context stack) і крок за кроком розгортає матріошку викликів:

pow(2, 3) = 2 * pow(2, 2)
pow(2, 2) = 2 * pow(2, 1)
pow(2, 1) = 2 (Базовий випадок, зупинка!)

Після досягнення бази стек згортається у зворотний бік, перемножуючи результати: 2 * 2 * 2 = 8.
