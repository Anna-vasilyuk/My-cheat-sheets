Тренажер: Квадрати чисел від 1 до 9

Практичне порівняння роботи циклів for, while та do...while

← Назад до Хабу практики

Суть завдання

Завдання полягає в тому, щоб послідовно перебрати всі числа від 1 до 9, піднести кожне з них до квадрата (помножити на самого себе) та вивести результат користувачу. Нижче представлено три різні варіанти коду, які виконують цю роботу.

Варіант 1. Через цикл "for"

Класичний варіант, де початок, умова та крок лічильника зібрані в одному рядку: 

for (let i = 1; i <= 9; i++) {
  alert(i * i);
}

Варіант 2. Через цикл "while"

Варіант із передумовою, де лічильник створено заздалегідь, а крок i++ виконується наприкінці тіла циклу: 

let i = 1;
while (i <= 9) {
  alert(i * i);
  i++;
}

Варіант 3. Через цикл "do...while"

Варіант із постумовою, де перша дія виконується гарантовано без початкових перевірок умови: 

let i = 1;
do {
  alert(i * i);
  i++;
} while (i <= 9);
