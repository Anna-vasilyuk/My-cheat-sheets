Логічна пастка: if ("0")

Як JavaScript перетворює рядки на логічні значення всередині умов

← Назад до Хабу практики

Суть питання

У JavaScript інструкція if (...) завжди автоматично перетворює будь-яке значення всередині круглих дужок на булевий тип — true або false.

Розглянемо класичний приклад, на якому часто помиляються початківці: 

if ("0") {
  alert('Привіт');
}

Чому це працює саме так?

Правило перетворення рядків:

У JavaScript діє залізне правило: будь-який непустий рядок завжди перетворюється на true.

Текстовий рядок "0" містить у собі один символ (цифру нуль), тому він **не є порожнім**. Двигун JavaScript бачить це як правду (true) і запускає код у блоці.

Порівняння з числом 0

Не плутайте текст із числом! Якби всередині дужок стояло чисте число 0 без лапок, воно б перетворилося на порожнечу (false), і вікно не з'явилося б: 

if (0) { 
  alert('Цей код ніколи не запуститься'); 
}

Закріпимо

Перевір цю пастку в дії прямо зараз!

Чи буде показано alert?

Натисни кнопку нижче, щоб запустити цей код на виконання. Браузер перевірить умову if ("0") і дасть фінальну відповідь.
